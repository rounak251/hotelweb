# Luxury Stays: Hotel Landing Page

**Live demo:** https://rounak251.github.io/hotelweb/

A single-page hotel website built with plain HTML and CSS, with no frameworks.

## Features
- Sections for rooms, services, gallery, testimonials and a contact form
- Smooth in-page navigation from the header menu
- CSS keyframe animations (fade-in, slide-down) and hover effects on cards
- Responsive flexbox layout that wraps on small screens

## Run locally
Open `index.html` in any browser.
